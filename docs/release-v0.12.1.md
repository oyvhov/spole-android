# Spole 0.12.1 · Popupane held plassen sin

- **X øvst til høgre:** same topplinje på filmar, episodar, kalender, avspeling, innlogging og førespurnader. Knappen flyttar seg ikkje med kort tittel eller rulling.
- **Rulling flyttar berre innhaldet:** heile arket blir ikkje lenger drege med når du når toppen. Bruk X, trykk utanfor eller Android Tilbake for å lukke.
- **Stabil ramme på alle popupane:** også innloggingssteg, feilmeldingar og avspelingsoppdateringar held seg inni den faste høgda.
- **Lukkeanimasjon:** X lèt arket gli ut før det blir fjerna.
- **Trygg sending:** Android Tilbake kan ikkje lukke ei førespurnad medan ho blir send.

Rett plassering og gesthandtering er kontrollerte på emulator med ekte Jellyfin-/Emby-data. Biletrate på ein fysisk telefon er ikkje målt.
