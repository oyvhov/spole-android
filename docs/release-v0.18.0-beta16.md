# Spole 0.18.0-beta16

- **Høgare mobil-toppmeny:** Logo, søk og profilbilde ligg nærare toppen frå starten. Systemmargane blir brukte éin gong og tilpassar seg statuslinje og kamerautskjering.
- **Stabil detaljkunst:** Film- og seriepopupen brukar riktig bakgrunn frå opninga og held biletet stabilt når metadata kjem, på mobil og TV.
- **Rolig innlasting:** Manglande bakgrunn tonar inn utan eit glimt av poster eller miniatyrbilete først. Parallax og touch-sveiping er bevarte.

Same pakkenamn og signatur som før. Oppdateringa bevarer kontoar, profilar og innstillingar.
