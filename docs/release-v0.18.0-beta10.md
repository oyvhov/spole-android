# Spole 0.18.0-beta10

Denne testutgåva gir innstillingar, undermenyar og detaljsider eit opnare uttrykk på TV og mobil.

## Menyar og tilpassing

- Frittståande ikon og luftige rader i innstillingar og undermenyar, med tydeleg fokus på TV.
- Visuelle døme ved val av mellom anna bakgrunn, aksentfarge, biletstorleik og hjørne.
- **Sider og meny** samlar tilpassing av framsida, biblioteksida og menyvala.
- Biblioteksider får ein felles editor for synlegheit, rekkjefølgje, innhaldsrader og vising.
- Filterlinja får korte etikettar. Sett-status og oppløysing ligg under **Filter**, og aktive filter blir viste som tekst.
- Hovudsidebaren har same utsjånad som før.

## Film, seriar og avspeling

- Kjeldenamnet tek mindre plass i detaljvisinga. Metadata og vurderingar får betre plass og kan bryte over fleire linjer.
- Vurderingar frå biblioteket blir tekne med inn i detaljane og blir ikkje fjerna når eit oppfølgingskall manglar dei.
- Større episodekort på TV, opne sesongfaner og framdrift under episodebiletet.
- Val av lyd, tekst og kvalitet bruker opne rader og hake ved valt alternativ. Kvalitetsvala har korte forklaringar.

## Søk og innlasting

- Eit ope søkjefelt, historikk som rader og bibliotektreff grupperte etter medietype.
- Lettare tekstfaner i Oppdag og rolegare tomvisingar.
- Lasteplasshaldarar med plakatformat, tekstlinjer og dempa lysrørsle.

## Endra innstillingsval

Bibliotekoversikta er no den faste biblioteksida, med tilpassing av radene i editoren.
Vurderingar og bilete-/lydkvalitet blir viste når data finst. Logo og storleik i utvalet følgjer
innhaldet og visingsvala. Komande episodar blir viste når Seerr er kopla til.

## Kontroll og avgrensingar

Dei visuelle endringane er gjennomgåtte på TV med ekte bibliotek og på mobil med den eksisterande
demoprofilen. Sjå verifikasjonsrapporten i kjelda for bygg- og oppdateringskontroll.
Automatiske einings- og instrumenteringstestar er ikkje køyrde på nytt for denne releasen.
Globalt søk på TV og personsøk er ikkje utvida i denne utgåva.
