# Spole 1.0.0-beta20

«Episode 5» i staden for «TBA». Produksjonskode 157.

- Episodar utan namn heiter «Episode 5» på episodekorta, også kommande episodar frå Seerr.
- «TBA», «TBD», «N/A» og «-» er fjerna frå tekstane på smarthyller, i barnemodus, i nedlastingar og i radene.

Alt frå beta19 er med. Kjeldearkiva for FFmpeg og dei native undertekstbiblioteka ligg ved releasen.
