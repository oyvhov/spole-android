# Spole 1.0.0-beta3

Spole får ein ny personleg kalender med Seerr, og treng ikkje lenger direkte tilkoplingar til Sonarr eller Radarr.

- Ei roleg datooversikt viser episodar og digitale filmpremierar dei neste 28 dagane, med filter for film og episodar.
- Episodar som kjem same dag blir samla, med ei oversikt som kan utvidast. Heim viser neste hending per serie.
- Kalenderen bruker seriane du ser på, seriefavorittar, eigne aktive førespurnader og titlar du vel å følgje. Du kan òg skjule ein automatisk inkludert tittel.
- Titlar utan dato i perioden får eiga liste. Datoane er premieredatoar; dei lovar ikkje at innhaldet finst på tenaren.
- Kalenderen kan bli klar før den større gjennomgangen av filmutgjevingar. Heile kalenderen og alle sider med eigne førespurnader blir bevarte.
- Gamle Sonarr-/Radarr-tilkoplingar og nøklar blir rydda bort ved oppgradering. Jellyfin, Emby, Seerr, tema, bibliotekval og personlege innstillingar blir bevarte.

Manuelle følgjeval er lokale per profil og Seerr-konto på kvar eining. Seerr sine tenartenester for automatisk henting blir ikkje erstatta eller endra.

Installer over førre versjon. Testutgåver må vere på i oppdateringsinnstillingane.
