# Spole 1.0.0-beta18

Ny avspelar: roleg OSD, eigne undertekstar og framdrift utan nett. Produksjonskode 155.

- Eitt roleg OSD med «Avspelingsval»: lydspor, undertekstar, kapittel, fart, lyd- og tekstforsinking, kvalitet, biletfylling, minispelar og statistikk.
- ASS/SSA med originale stilar og fontar, teikna i appen. For store originalar fell tilbake til tenaren sin tekst.
- PGS/SUP og DVD-tekst i MKS lokalt, utan innbrenning på tenaren.
- Førehandsbilete ved spoling (Jellyfin trickplay).
- Mobil: lysstyrke, volum og knip i biletet.
- Framdrift frå nedlastingar blir send når nettet er tilbake. Ny innlogging tømmer ikkje køa.
- Tekst som varer lenger enn videoen, hindrar ikkje lenger at episoden sluttar.
- TV: heroen på Heim byter tittel også med fokus på knappane.

Kjeldearkivet for dei native undertekstbiblioteka (libass, FriBidi, FreeType, HarfBuzz, Fontconfig, Expat, libunibreak) ligg ved releasen, saman med FFmpeg-kjelda.

Sjå [verifiseringa](https://github.com/oyvhov/spole-android/blob/main/docs/VERIFICATION_v1.0.0-beta18.md).
