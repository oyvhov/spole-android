# Spole 0.16.0-alpha17

- Lagra Jellyfin- og Seerr-tilkoplingar blir ikkje lenger presenterte som sletta når ein mellombels profilkontroll feilar.
- Innstillingane viser at innlogginga framleis er lagra og gir eit tydeleg nytt forsøk.
- Dersom Seerr-tenaren ikkje kan bruke Quick Connect, byter appen automatisk til innlogging med Jellyfin-konto i same ark.
- Feilmeldinga forklarer kva innloggingsmåte som skal brukast, utan at tenaradressa må skrivast inn på nytt.

Testutgåve, bygg 60. Installer over den eksisterande Spole-appen for å behalde kontoar og innstillingar.
