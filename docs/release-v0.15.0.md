# Spole 0.15.0 · Jellyfin-spelar

- Sjå filmar og episodar frå Jellyfin direkte i Spole.
- Vel sesong og episode, eller hald fram frå posisjonen lagra på din eigen konto.
- Fullskjerm, pause, spoling, lydspor, undertekst og val for lågare databruk.
- Tekstspor kan bytast utan å starte videostraumen på nytt. Avspelinga tek pause når appen går i bakgrunnen.
- Jellyfin får no namnet **Spole**, ikkje HomeReel, ved innlogging og avspeling.

Installer APK-en over den eksisterande appen. Same pakkenamn, signeringsnøkkel og lagra einings-ID er bevarte.

Spelaren krev ein personleg Jellyfin-konto med avspelingsrettar. Nokre format krev omkoding på tenaren.
Emby-avspeling, Chromecast, bilete-i-bilete og offline-nedlasting er ikkje med i denne versjonen.
Ekte Jellyfin-video er prøvd i emulator; alle format og yting på fysisk telefon er ikkje ferdig verifiserte.
