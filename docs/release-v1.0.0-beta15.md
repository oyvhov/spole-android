# Spole 1.0.0-beta15

Stødig fokus på TV-framsida og lettare førespurnader. Produksjonskode 152.

- TV-framsida: fokus hoppar ikkje lenger til sidemenyen når heroen byter tittel, og startar på «Spel av».
- Mobil: «Be om» ligg fast nedst på tittelsida, slik «Spel av» gjer.
- Ein film er eitt lite ark med «Send førespurnad»; på TV får det plass på éin skjerm og startar på knappen. Seriar beheld sesongvalet.
- Oppdag på TV: rada med fokus legg seg rett under toppfeltet, og førespurnadene dine viser eige bilete og samandrag.

Sjå [verifiseringa](https://github.com/oyvhov/spole-android/blob/main/docs/VERIFICATION_v1.0.0-beta15.md).
