# Spole 0.17.0-beta33

Redesign av barnemodus med filmatisk hero, ekte biblioteksbilete og «Mi verd» integrert i profilknappen.

## Nytt og forbetra i barnemodus

- **Filmatisk hero på barneframsida:** Hero-banneret dekkjer heile breidda i toppen, tonar naturleg inn i fargetemaet (himmel og atmosfære) for den valde verda, og viser klare titlar, logo og ein stor barnevennleg knapp («Sjå no» / «Sjå vidare» / «Vel episode»).
- **Fjerna lausriven toppbar:** Profilknappen er no elegant integrert øvst i høgre hjørne av hero-banneret med trygge system-insets.
- **«Mi verd» samla i profilknappen:** Ved å trykkje på barneavataren opnar ein dialog med to val:
  1. *Mi verd* (utan PIN): Barnet kan fritt velje fargetema, stjerner og landskap.
  2. *Byt profil* (krev PIN): Sikker utgang for foreldre tilbake til vaksenprofil eller andre profilar.
- **Ekte biblioteksbilete frå Emby og Jellyfin:** Bibliotekskorta for barn viser no tenaren sine 16:9-omslagsbilete med autentisert biletlasting for Emby, i staden for enkle tekstbrikker.
- **Ingen syntetisk «Alt»/«Alle»-kategori:** Barnevisinga opnar direkte på det første ekte barnebiblioteket (t.d. «Barne-Tv Serier» eller «Barnefilmar»), og filtrerer innhaldet strengt til det valde biblioteket.
- **Spissa og levande verd-tema:** Kvar verd (Verdsrom, Havdjup, Eventyrskog, Nordlys, Solnedgang, Kino) styrer no dynamisk himmel, glød, knappefargar, fokusrammer og atmosfæriske detaljar.
