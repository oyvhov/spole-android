# Spole 0.18.0-beta14

- **Oppdatering på TV:** Varselet får fokus på «Sjå oppdatering». Fjernkontrollen kan velje «Seinare», opne oppdateringa og bruke nedlasting, avbryt og installer. Tilbake lukkar varselet.
- **Mjukare Hero:** Lengre biletovergang på TV, klargjorde logoar og stabile handlingsknappar. Mobilframsida har ein eigen Hero med snarveg til avspeling og detaljar.
- **Rolegare spoling:** Éin tidsverdi med retningsikon, utan doble tal eller nullblink. TV spelar i originalt bildeformat utan «Fyll skjermen»-kontrollen.
- **Seriesida:** Sesongane er flytta nærare handlingane, med rom under logoen og betre avstand mellom opplysningane. Speletida står diskret på episodebiletet.
- **Hald fram:** Nesten ferdige episodar blir ikkje tekne tilbake av lokal framdrift. Appen bruker Jellyfin sin status etter rapportering og bevarer tenaren sine eigne fullføringsgrenser.

Same pakkenamn og signatur som før. Oppdateringa bevarer kontoar, profilar og innstillingar.
