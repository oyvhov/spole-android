# Spole 0.17.0-beta23

- Fleirprofil-støtte med fullstendig isolasjon mellom hovudkonto og barnekontoar; eksisterande innlogging held fram uendra.
- Profilbyte rett frå avatar-ikonet øvst til høgre (ProfileSwitcher) med 64 dp rader og D-pad fokus.
- Legg til barnekonto frå tenaren (Users/Public) eller direkte med brukarnamn og passord ved gøymde kontoar.
- 4-sifra PIN-sikring (salta SHA-256) med to-stegs stadfesting, progressiv utestenging som overlever omstart, og nummertast-støtte på TV-fjernkontroll.
- Innstillingsfana er skjult i barnemodus; retur til hovudkonto krev PIN.
- Forbetra ikon og design på nedlastings- og oppdateringssida.
- Rett biletvising på «Hald fram å sjå» for Jellyfin og Emby.
- Mjukare og jamnare navigering i TV-innstillingar.
- Reinare OSD-kontrollar på mobil.

Universal-APK for telefon og TV. Same signatur, versjonskode 102.
Oppdater via Appoppdateringar → Sjekk no, med testutgåver på.

FFmpeg-koden er uendra; lisensar og tilsvarande kjelde-/relenkingsarkiv følgjer med.
