# Spole 1.0.0-beta33

Oppdag i Stova. Produksjonskode 170.

- Stova kan vise Oppdag frå Seerr med Spole si innlogging: rader, tittelside, sesongar, liknande titlar og søk.
- Stova kan be om og trekkje tilbake ein førespurnad gjennom Spole, som personen.
- `spole://discover` opnar ein Seerr-tittel i Spole, også frå kald start.
- Oppdag er berre for vaksne profilar, med ei eiga melding for ein barnekonto.
- Ingen token eller Seerr-adresse går over til Stova.

Versjonsnamnet beta32 gjekk til eit lokalt testbygg og blir hoppa over. Alt frå beta31 er med.
Kjeldearkiva for FFmpeg og dei native undertekstbiblioteka ligg ved releasen.

Sjå [verifiseringa](https://github.com/oyvhov/spole-android/blob/main/docs/VERIFICATION_v1.0.0-beta33.md).
