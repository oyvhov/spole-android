# Spole 0.13.2 · Ein mjukare start

- Animert «Spole»-ordmerke og diskret lastelinje ved oppstart.
- Framsida lastar bak oppstarten og tonar fram. Ventinga på tenestedata er avgrensa.
- Mindre ikonsymbol med meir luft på Android.
- Eiga nedlastingsrad og tilhøyrande heimeinnstilling er fjerna. Framdrift på førespurnader blir verande i Aktivitet.
- GitHub-overskrift, prosjektomtale og nedlastingsnamn bruker Spole.

203 einingstestar og 6 Android-testar bestod. Ingen lint-feil (26 åtvaringar). Oppstarten er kontrollert frå emulatoropptak med demodata. Oppdatering frå 0.13.1 bevarte demovala. Ekte tenestekontoar er ikkje testa i denne runden.

Installer `Spole-v0.13.2.apk` over eksisterande app; pakkenamn og signeringsnøkkel er uendra.
