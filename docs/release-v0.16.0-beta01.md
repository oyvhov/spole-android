# Spole 0.16.0-beta01

Hovudoppgradering frå alpha24 med UI-forbetring og betre intern flyt.

- Heime-radenes rekkjefølgje kan lagrast frå Innstillingar, og du kan flytte den tilpassa bruken din.
- Bokmål er no støtta som språkval, med eigne ressursar og lokalitetssentral i manifestet.
- Filmar får vurdering på omslaga der tenesta tilbyr data.
- Tenestestatus i Tenester blir vist med status som eigne oppføringar i tenesteinnstillingane.
- Éin-knapp utlogging gjer det enklare å kome tilbake til innloggingsstaten på eininga.
- Bottom navigation på smale telefonskjermar har no adaptive, kortare etikettvariasjonar som sparer plass.
- Episodelistar og detaljar bruker lågare tekstmengde i hovudkort, slik at meir innhald kjem til syne.
- Demo-data er utvida med meir realistiske titlar, coverbilete og sesongtema (inkludert Jul og Halloween), og gjer test av heimesida enklare.

Dette er ein testutgåve. Oppgrader over eksisterande installasjon av Spole for å behalde kontoar og innstillingar.
