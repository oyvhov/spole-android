# Spole 1.0.0-beta30

Spole og Stova saman. Produksjonskode 167.

- Stova kan vise radene til ein Spole-person («Hald fram», nye filmar og nye seriar), med aldersgrense, og éitt kort per serie.
- Stova kan be Spole merkje ein tittel som sett, fjerne han frå «Hald fram» og spele han frå starten.
- Spole seier frå når ein film spelar, pausar eller stoppar, så kino-modus i Stova kan dimme lysa.
- Emby gir aldersgrensa på titlane, og norske aldersgrenser står som «15 år» og «Alle».
- På TV blir kortet du står på ikkje kutta ved høgre kant, og høgre-pila stoppar ved enden av rada.
- Resten av hylla blir ikkje lenger dempa når du står på eit kort, som i Stova.

Alt frå beta29 er med. Kjeldearkiva for FFmpeg og dei native undertekstbiblioteka ligg ved releasen.

Sjå [verifiseringa](https://github.com/oyvhov/spole-android/blob/main/docs/VERIFICATION_v1.0.0-beta30.md).
