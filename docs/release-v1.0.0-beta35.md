# Spole 1.0.0-beta35

Toppmenyen på TV: liten og berre øvst. Produksjonskode 172.

- Små ord rett på biletet, med profilsirkelen til høgre. Han har ingen mørk stripe og ingen kapsel, og ei kort aksentstrek står under sida du er på.
- Menyen rullar vekk med sida på Heim, på biblioteksida, inne i bibliotek og på smarthyllene, og kjem att når du går opp.
- Menyen følgjer «Sider og meny»: rekkjefølgja di, og biblioteka dine også utan festing. Søk står sist, og Innstillingar ligg bak profilsirkelen.
- Profilmenyen opnar på profilen du brukar. Fokus går til sida når flisa du stod på forsvinn.
- «Neste» på biblioteksidene har Heim-korta, og episodar i søket er 16:9.

Oppdag, Nedlastingar og Innstillingar har framleis menyen fast øvst.
Versjonsnamnet beta34 gjekk til eit lokalt testbygg og blir hoppa over. Alt frå beta33 er med.
Kjeldearkiva for FFmpeg og dei native undertekstbiblioteka ligg ved releasen.

Sjå [verifiseringa](https://github.com/oyvhov/spole-android/blob/main/docs/VERIFICATION_v1.0.0-beta35.md).
