# Spole 1.0.0-beta40

Kvart trykk byggjer berre det som endrar seg. Produksjonskode 177.

- TV: Eit trykk byggjer ikkje lenger om korta som nettopp kom til syne. Det første biletet etter eit trykk tok 14–20 ms på Shield, no under 1 ms.
- TV: Korta har færre usynlege delar i tilgjengelegheitstreet.
- TV: Radene på bibliotek- og detaljsidene går ut til skjermkanten og tonar ut der, som på Heim.
- TV: Toppmenyen står når profilmenyen er open, og ingenting bak ein meny har fokusring.
- Lydspor og undertekstar heiter til dømes «Norsk · SRT» i staden for «Norwegian - SUBRIP».
- Samlingar viser ikkje lenger eit årstal.

Alt frå beta39 er med. Kjeldearkiva for FFmpeg og dei native undertekstbiblioteka ligg ved releasen.

Sjå [verifiseringa](https://github.com/oyvhov/spole-android/blob/main/docs/VERIFICATION_v1.0.0-beta40.md).
