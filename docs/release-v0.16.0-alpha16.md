# Spole 0.16.0-alpha16

- Biblioteka har eigne hyller. Filmar og Seriar viser «Hald fram å sjå» og «Neste episode» for det biblioteket du faktisk står i.
- Hald inne eit bibliotek- eller hyllekort for å fjerne frå «Hald fram å sjå», setje favoritt eller markere som sett. Endringane blir skrivne til Jellyfin.
- Tittelsidene viser lydspor, undertekstar og versjon før avspeling. Sporevala blir sende med inn i Spole-spelaren.
- Tittelsida er stramma inn med færre blokker, tydelegare framdrift og større episodebilete.
- Episodeetikettar er skrivne ut som «Sesong 19 - Ep 9», og tomme serienamn frå Jellyfin blir ikkje lenger viste som blanke titlar.
- Bibliotekfilter og vising ligg på sida i staden for i ein popup, og bibliotek kan hugse vising, kortstorleik, bilettype og om titlar skal visast.
- Biblioteksnarvegar i menyen kan flyttast opp og ned.
- Oppdag på TV har søkefeltet synleg utan å hente fram tastaturet før du vel feltet.
- «Sjå førespurnadshistorikk» ligg på same linje som aktivitetsfiltera.
- Byter du plakat, thumbnail eller klarlogo i Jellyfin, får appen ny biletadresse og viser det nye biletet etter oppdatering.
- TV-helten har trygg toppavstand, rolegare fokus og rotasjon mellom fleire tilgjengelege bilete når dataa finst.
- Lint-opprydding og automatisk test for omsetjingsparitet mellom engelsk og nynorsk.

Testutgåve, bygg 59. Vel Appoppdateringar -> Sjekk no med Testutgåver på. Installer over den eksisterande Spole-appen.
