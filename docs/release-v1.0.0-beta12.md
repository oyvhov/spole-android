# Spole 1.0.0-beta12

Tettare gruppering av serienamn og episodar, og rettingar etter visuell gjennomgang av mobil, nettbrett og TV.
Produksjonskode 149, med same pakkenamn og signatur som tidlegare utgåver.

- Tittel og episode ligg samla etter faktisk teksthøgd. Ein kort tittel eller eit tomt episodefelt lagar ikkje lenger ei ekstra blank linje; kunstfelt og handlingsknappar held seg stabile.
- Betre plass til stor skrift på framsida og i nettbrett-heroen, og ryddigare episodetitlar, årstal og lydspornamn.
- Større avspelingsknappar og tydelegare spoling på nettbrett. Avspelingsstatistikken har ein tilgjengeleg lukkeknapp og tek imot Tilbake før spelaren blir lukka.
- Ryddigare TV-meny, biblioteksfilter, kalenderkunst og nedlastingsside.
- Rolegare Halloween- og julepynt, synlege sesonginngangar og betre førehandsvising av tema og undertekstar.
- Stødige konto- og oppdateringsdialogar og ei roleg, lesbar kjeldemeny.

Sjå [verifiseringa](https://github.com/oyvhov/spole-android/blob/main/docs/VERIFICATION_v1.0.0-beta12.md).
