# Spole 1.0.0-beta2

- Betre bibliotekvising på mobil og TV, med jamne kort og fokusramme rundt sjølve biletet.
- Vel cover, miniatyr, banner eller logo, rutenett eller liste og kortstorleik under «Vising».
- Eigne val for titlar, vurderingar, sett-merke og tal på usette episodar.
- «Hald fram» og «Neste episode» er samla i «Neste» i biblioteket, med eitt kort per serie.
- Film viser årstalet tett under tittelen, utan ei tom linje imellom.
- Raskare start på bilethentinga, mindre bilete tilpassa korta og roleg overgang ved kald lasting.
- Diskret kvit hake på sette filmar. Jellyfin og Emby held fram med eigne kjelder og innhald.

Versjonskode 139. Oppdaterer eksisterande Spole med same signatur.

Biblioteksendringane er kontrollerte med 84 relevante einingstestar, avgrensa Android-testar på mobil og TV og systemskrift 2.0. Siste justering av årstal bestod 3/3 Android-testar ved normal skrift og 3/3 ved stor skrift. Heile testsuiten blir ikkje repetert for versjonsauken.
