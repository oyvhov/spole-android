# Spole 0.13.3 · Ryddigare innstillingar og rolegare detaljar

- Matte, avrunda innstillingsgrupper og utvidbar «Tilpass framsida».
- Grøn hake for tilkopla tenester; feil og åtvaringar er framleis synlege.
- Coveret held seg synleg under detaljlasting. Metadata tonar inn utan å byte hero-layouten.
- Ryddig poster-/tekstlayout for filmar og seriar med poster.
- Varsam systemstyrt haptikk. Biletovergangar blir slått av når Android-animasjonar er deaktiverte.

Same pakkenamn og signeringsnøkkel som før: installer APK-en over eksisterande Spole.

Innstillingane og detaljendringane er tidlegare testa med høvesvis 3 og 10 Android-testar. Den endelege release-APK-en er ikkje installasjonstesta på nytt: emulatorens WSL-teneste svarte ikkje under publiseringa. Sjå verifiseringsnotatet for byggkontrollen.

Ekte cover-til-popup-overgang og utvida sesong-/episodevising er ikkje med enno.
