# Spole 1.0.0-beta13

Smarte hyller får eit tydeleg val av tenar og bibliotek. Produksjonskode 150.

- Nye hyller startar på vald tenarkonto og valt bibliotek. Frå rotnivået vel du bibliotek før lagring.
- Vel eitt eller fleire bibliotek i byggjaren. «Alle bibliotek» og «Alle tenarar» er uttrykkelege val.
- Avgrensinga gjeld innhaldet, førehandsvisinga, framsideradene, menyen og biblioteket. Bytte av tenar, konto eller tilkoplingsadresse blandar ikkje hyllene.
- Eldre hyller og sesongmalar er bevarte som «Alle tenarar» og kan avgrensast i «Endre».
- Inneheld òg beta12 sine rettingar av tekstavstand, nettbrettspelar og grensesnitt.

Sjå [verifiseringa](https://github.com/oyvhov/spole-android/blob/main/docs/VERIFICATION_v1.0.0-beta13.md).
