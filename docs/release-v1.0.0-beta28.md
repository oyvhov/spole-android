# Spole 1.0.0-beta28

Eigne profilar, og Spole saman med Stova. Produksjonskode 165.

- Eigen profil for ein annan person sin konto i hovudprofilen (Tenestene dine → Profilar): vanlege Spole med berre den kontoen, i profilmenyen i hjørnet, utan ny innlogging.
- Stova kan logge inn ved at Spole godkjenner Quick Connect-koden, får vite kvar avspelinga stoppa, opnar Spole som ein bestemt person og tek Spole med ved profilbyte. Ingen innlogging blir delt mellom appane.
- Siste Tilbake frå eit bibliotek eller ein tittel Stova opna, går tilbake til Stova.
- Hovudprofilen blir ikkje lenger kalla opp etter ein konto som har sin eigen profil.

Alt frå beta27 er med. Kjeldearkiva for FFmpeg og dei native undertekstbiblioteka ligg ved releasen.

Sjå [verifiseringa](https://github.com/oyvhov/spole-android/blob/main/docs/VERIFICATION_v1.0.0-beta28.md).
