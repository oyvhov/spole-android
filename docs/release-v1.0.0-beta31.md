# Spole 1.0.0-beta31

Eitt rørslespråk, toppmeny på TV og profilbyte som ei rørsle. Produksjonskode 168.

- Fem faste rørsler i heile appen; redusert rørsle tonar i staden for å kutte.
- Radene på Heim kjem inn éi og éi når innhaldet er klart.
- Profilbyte: biletet flyg til profilsirkelen, og dei nye radene kjem etter landinga.
- TV: valfri toppmeny med Heim, festa bibliotek, Oppdag og Søk; Innstillingar bak profilsirkelen.
- Søk på TV med eige tastatur ved sida av treffa.
- Rolegare søk, hopp over resymé og førehandsvising, lyd og undertekst hugsa per serie, episoderada opnar på neste episode.
- Éin framdriftsline, varselfargar som følgjer aksenten, profilfargar frå namnet, heildekkjande tekst over bilete.

Alt frå beta30 er med. Kjeldearkiva for FFmpeg og dei native undertekstbiblioteka ligg ved releasen.

Sjå [verifiseringa](https://github.com/oyvhov/spole-android/blob/main/docs/VERIFICATION_v1.0.0-beta31.md).
