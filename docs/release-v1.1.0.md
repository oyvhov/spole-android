# Spole 1.1.0

Søket viser treff frå Jellyfin, Emby og Seerr etter kvart som tenestene svarar. Om ei teneste feilar, kan du prøve igjen og behalde treffa frå dei andre.

Det er lettare å hente fleire treff, og søket skil betre mellom filmar, seriar og ulike utgåver med same namn. Du kan tømme søkjehistorikken for den aktive profilen.
