# Spole 0.13.1 – oppdatert avspelingsstatus

- Spelar no og avspelingsdetaljane hentar fersk status kvart femte sekund medan appen er synleg.
- Framdrift, attståande tid, pause og aktive økter blir oppdaterte utan manuell oppfrisking.
- Når ingen spelar, blir nye økter sjekka kvart 15. sekund. Oppdateringane stoppar i bakgrunnen.
- Berre avspeling og nødvendige kontorettar blir henta; bibliotek og anbefalingar blir ikkje lasta på nytt.
- Vanlege brukarar ser framleis berre eigne økter.

Installer som oppgradering over førre versjon.
