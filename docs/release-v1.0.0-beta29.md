# Spole 1.0.0-beta29

Heim på TV som i Stova. Produksjonskode 166.

- Stort toppbilete ned til den første hylla, som står heil nedst på skjermen; resten av radene kjem når du går ned.
- Toppbiletet viser ratingar fyrst, så år, lengd eller tid att og aldersgrense, to liner med handling og ein større logo. Biletet syner meir og går vidare bak hylla.
- Korta har Stova sin stil som standard: runde hjørne, fokus som løftar kortet utan ring og dempar dei andre, og framdrift i aksentfargen. Fokusvalet heiter «Løft, som Stova» under Utsjånad.
- Miniatyrbileta i «Sjå vidare» blir ikkje lenger forstørra så tittelen blir kutta.

Alt frå beta28 er med. Kjeldearkiva for FFmpeg og dei native undertekstbiblioteka ligg ved releasen.

Sjå [verifiseringa](https://github.com/oyvhov/spole-android/blob/main/docs/VERIFICATION_v1.0.0-beta29.md).
