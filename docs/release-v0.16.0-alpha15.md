# Spole 0.16.0-alpha15

- TV-toppfeltet har meir luft over seg og rolegare typografi.
- «Utforsk tittelen» er bytt med ein diskret «Sjå meir»-knapp.
- Jellyfin-/Emby-logo og namn erstattar biblioteksetninga.
- Toppfeltet glir mjukt mellom opptil tre ulike seriar kvart åttande sekund. Fleire episodar av same serie blir ikkje valde.
- Rotasjonen pausar ved fjernkontrollfokus, opne detaljar, når feltet er ute av syne og når appen er i bakgrunnen. Avslåtte systemanimasjonar stoppar automatisk rotasjon.
- Den lyse ringen rundt profilbiletet er dempa.

Testutgåve, bygg 58. Vel Appoppdateringar → Sjekk no med Testutgåver på. Installer over den eksisterande Spole-appen.
