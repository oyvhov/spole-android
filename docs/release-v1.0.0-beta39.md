# Spole 1.0.0-beta39

Gjennomgang på Loftet: oppdatering, overskrifter og innstillingar. Produksjonskode 176.

- Oppdatering i appen: «Installer oppdatering» opnar Android-installasjonen ved første trykk, frå neste oppdatering.
- TV: Alle overskriftene på Heim er like store.
- TV: Innstillingane går ned til botnen av skjermen og tonar ut der, utan ei skoren tekstlinje.
- TV: Oppdag viser ikkje plakaten som ei smal stripe bak sida når bakgrunnsbiletet manglar.
- TV: Kvart kort er eitt stopp for tilgjengelegheitstenester, og tenestene har mindre å gå gjennom.
- Bokmål: 15 tekstar med nynorske ord er retta, mellom anna «Kommende» og «Tøm bildebuffer».

Alt frå beta38 er med. Kjeldearkiva for FFmpeg og dei native undertekstbiblioteka ligg ved releasen.

Sjå [verifiseringa](https://github.com/oyvhov/spole-android/blob/main/docs/VERIFICATION_v1.0.0-beta39.md).
