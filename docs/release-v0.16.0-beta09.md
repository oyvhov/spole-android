# Spole 0.16.0-beta09

Denne betaversjonen samlar ytelsesendringar for API-transport og heimefeed.

- Brukar ein delt OkHttp-klient med connection pooling og HTTP/2 for tenestekall.
- Reduserer unødvendige felt på heimekort og avgrensar serieoppslag for Neste opp.
- Skriv Jellyfin-data til offline-cache når berre ei underliggande teneste feilar.
- Heroen hentar no kandidatar frå framhald, Neste opp, filmar og seriar i roleg rotasjon.
- `versionName=0.16.0-beta09`, `versionCode=76`.

Dette er ein testutgåve.
