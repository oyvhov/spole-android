# Spole 0.16.0-alpha23

- Fiksa venstretasten mellom plakatar og fokus på aktiv side i TV-menyen.
- Ny, kompakt episodedetaljside med breitt bilete og to linjer omtale før «Les meir».
- Heile heroen kjem fram når fokus går opp att; verktøy og filter peikar ned til første tittel.
- Eitt trykk tilbake lukkar OSD, også frå lyd-/tekst-/kvalitetsval under pause.
- Neste-episode-kort med tydeleg fokus, episodens bilete, meir gjennomsiktig bakgrunn og grafisk nedteljing.
- Portrett for medverkande når serveren har bilete, nytt filmikon og små tenestesymbol i menyen.
- Slått av servergruppering av samlingar i filmbiblioteket.

Universal, signert produksjons-APK med versjonskode 66. Oppdaterer eksisterande Spole og bevarer kontoar og val.
