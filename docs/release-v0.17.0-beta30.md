# Spole 0.17.0-beta30

Barnemodus har fått ny startside, tydeleg fjernkontrollfokus og seks personlege tema:
Verdsrom, Havdjup, Eventyrskog, Nordlys, Solnedgang og Kino. Barnet vel utsjånad i
«Mi verd». Foreldre kan styre tilgangen og velje undertekstar, redusert rørsle og
autospel med pause etter 1–3 episodar. Dette er ikkje ein dagleg skjermtidsgrense.

«Tenestene dine» har nytt oppsett med direkte tilgang til foreldrevala. «Opne
kontoinnstillingar» opnar no denne sida direkte. Bibliotekfilter, nettverksfeil,
profilbyte og vising av episodetitlar og episodebilete i barnemodus er retta.

Skjuling av menyval fungerer no. Heim og Innstillingar kan ikkje skjulast, og
Bibliotek er verna når det er startside. Menyredigeraren har tydelege brytarar og
separate flytteknappar. På telefon i liggjande vising får du ei kompakt sidemeny
med Innstillingar fast nedst.

Oppdateringa bevarer eksisterande kontoar og val. Ho er ei testutgåve;
«Testutgåver» må vere på i appoppdateringar for å finne henne.
