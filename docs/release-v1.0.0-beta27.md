# Spole 1.0.0-beta27

Førehandsbiletet ved spoling ligg der du spolar. Produksjonskode 164.

- Biletet ligg rett over spolepunktet på tidslina og følgjer det, i staden for midt på skjermen.
- Enklare bilete: tynn kant og tida inni, utan boks rundt og utan «+10 s» oppå.
- Med skjulte kontrollar på TV ligg biletet over tida nedst på skjermen.

Alt frå beta26 er med. Kjeldearkiva for FFmpeg og dei native undertekstbiblioteka ligg ved releasen.

Sjå [verifiseringa](https://github.com/oyvhov/spole-android/blob/main/docs/VERIFICATION_v1.0.0-beta27.md).
