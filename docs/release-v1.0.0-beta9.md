# Spole 1.0.0-beta9

Denne betaen strammar inn mobilframsida og gjer avspelingar og førespurnader lettare å lese.
Produksjonskode 146, med same pakkenamn og signatur som tidlegare utgåver.

- Mindre luft mellom hero-prikkane og «Sjå vidare» på mobil. Biletstorleiken, treffflatene og plass til stor skrift er bevarte.
- «Spelar no» viser heile cover og tydeleg tekst. Popupen har fast plass til bilde og handlingar, og ein kan velje mellom fleire økter.
- Heim oppdaterer Emby-avspelingar kvart tredje sekund; popupen sjekkar Jellyfin og Emby kvart andre sekund. Nettverkstida kjem i tillegg. Nettverksfeil får automatisk nytt forsøk.
- Lågare toppfelt på TV, jamnare tittellinjer og kompakte «Neste»-kort i biblioteket på breie flater.
- Sesongførespurnader deler cover i Aktivitet. Ein sesongveljar held statusane og handlingane for kvar førespurnad skilde.
- Rolegare TV-fokus og namn ved ikon i ein samanfalda sidemeny.

Basert på beta8 med sesongtema og smarte hyller.
Sjå [verifiseringa](https://github.com/oyvhov/spole-android/blob/main/docs/VERIFICATION_v1.0.0-beta9.md).
