# Spole 0.18.0-beta12

Detaljvisinga på mobil får eit meir samla, filmatisk uttrykk, inspirert av Infuse.

- Biletet går heilt ut til kantane på telefon. Tittel eller serielogo, episodeopplysningar, sjanger og vurderingar ligg samla over ein mørk overgang.
- «Spel av» / «Hald fram» ligg fast nedst, over gestfeltet. Du kan rulle gjennom omtalen, sporval og episodar utan å miste knappen.
- «Detaljar»-overskrifta er fjerna. Lukkeknappen ligg fast over kunsten.
- Detaljarket får meir plass på telefon og held høgda stabil medan metadata kjem inn.
- Knappetekst og TMDB-merke veks med teksten og får plass ved skriftstorleik 2.0.

Kontoar og lagra val blir bevarte. Dette er ei testutgåve; «Testutgåver» må vere på for å få henne gjennom appoppdateringar.

Testkontroll: 810 JVM-testar bestod. Mobilvisinga er kontrollert ved vanleg og dobbel tekststorleik. 15 av 16 utvalde Android-testar er stadfesta; ein eldre tastaturtest feilar på tidsfrista for lukking, som i beta11. Sjå verifikasjonsrapporten i kjelda for detaljane.
