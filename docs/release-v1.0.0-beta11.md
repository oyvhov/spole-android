# Spole 1.0.0-beta11

Enklare spoling på mobil og nettbrett, større tidslinje og betre lagring av episodeframdrift.
Produksjonskode 148, med same pakkenamn og signatur som tidlegare utgåver.

- Dobbeltrykk på venstre eller høgre side av videoen for å hoppe 10 sekund. Store sideflater tek imot trykka, også medan videoen bufrar etter eit hopp.
- Reine spolingsikon ute på kvar side, med ein diskret visuell puls. Ingen forklaringstekst eller ekstra boksar i gestvisinga.
- Større tidslinje på nettbrett i både ståande og liggjande format: 64 dp dragområde, større handtak og tydelegare tidsmerke.
- Pause og bakgrunn lagrar framdrift, også under bufring. Pausa spelarar sender ikkje stadig same posisjon til tenaren.
- Ny framdrift frå tenaren får ta over etter stadfesta lokal lagring, og Heim oppdaterer personlege rader når ei avspelingsøkt endrar seg.

Tek vare på endringane i smarte hyller frå beta10.
Sjå [verifiseringa](https://github.com/oyvhov/spole-android/blob/main/docs/VERIFICATION_v1.0.0-beta11.md).
