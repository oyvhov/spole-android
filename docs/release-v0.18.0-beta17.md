# Spole 0.18.0-beta17

Preview-boksen ved spoling er fjerna frå mobil og TV. Play- og spoleknappane held same plass ved spoletrykk og drag på tidslinja. TV held på den kompakte tidsvisinga.

Versjonskode 137. Oppdaterer eksisterande Spole med same signatur.

Verifisert før release: 837 einingstestar, ingen lint-feil og 3 spelartestar både med normal skrift og systemskrift 2.0. Testane blir ikkje køyrde på nytt i denne kjappe releasen, etter brukarens ønske.
