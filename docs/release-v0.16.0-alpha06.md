# Spole 0.16.0-alpha06 · Nettbrett og enklare TV-innlogging

Signert testversjon, bygg 49. Oppdaterer eksisterande Spole-installasjon.

- Eiga TV-startside med tenesteval, tydeleg fjernkontrollfokus og enklare Quick Connect-rettleiing.
- Betre brei Oppdag-side og kompakte aktive avspelingar.
- Minimerbar sidemeny, nettbrettoppsett og vidare språkforbetringar.
- Stabilare detaljpanel og betre leseflyt/fokus.

Dette er ein førehandsversjon. TV-launcher/store-pakking, fysisk TV-test og reell Quick Connect-godkjenning på TV står att. Engelsk er framleis førehandsvising.

Kjeldekontroll før pakking: 283 einingstestar og 13 innloggings-/TV-testar bestod; førre TV-bolk verifiserte videodekoding og fjernkontroll på Google TV-emulator. Ingen påstand om full fysisk einingsdekning. Sjå verifikasjonsrapporten for byggkontrollen.
