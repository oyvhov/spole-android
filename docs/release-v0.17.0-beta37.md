# Spole 0.17.0-beta37

Denne testutgåva ryddar opp i barnemodus utan å fjerne mediaradene eller avspelingsknappane.

## Retta

- Bakgrunnsverda er tona ned og stjernene ligg rolegare bak innhaldet.
- Heroen er eit mindre, avrunda kort med éi fast framvising, kort tittel og éin tydeleg handling.
- Lang omtale og automatisk heltekarusell er fjerna frå barnemodus.
- Profilknappen er flytta til ein enkel topp, slik at han ikkje konkurrerer med hero-innhaldet.
- README-en blir halden i takt med versjonen, slik at GitHub Actions sin release-sjekk går grønt.

Oppdateringa bevarer innloggingar, mediedata, mediarader og brukarval. Ho er ei testutgåve;
«Testutgåver» må vere på i appoppdateringar for å finne henne.
