# Spole 1.0.0-beta14

Oppdag og førespurnadene dine på éin stad. Produksjonskode 151.

- Aktivitet er ikkje lenger ei eiga fane. «Dine førespurnader» står øvst i Oppdag med fanene Alle, På veg og Klare.
- Rolege rader frå Seerr: Populært no, Filmar og seriar som kjem, Folk og Sjangrar. Berre plakatar, ingen knappar under.
- På TV viser toppfeltet tittelen som har fokus. Søket finn folk med bilete, og kvar person har si eiga side.
- Tittelsida har handlingar som ord: Be om, Trekk tilbake, Varsel og Trailer, og rader med liknande og tilrådde titlar.
- Be om-arket kan velje 4K, kvalitet og lagringsstad for kontoar som har lov i Seerr.

Sjå [verifiseringa](https://github.com/oyvhov/spole-android/blob/main/docs/VERIFICATION_v1.0.0-beta14.md).
