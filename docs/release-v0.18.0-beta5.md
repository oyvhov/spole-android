# Spole 0.18.0-beta5

Denne testutgåva gjer offline-nedlasting meir naturleg og tryggare å bruke.

## Nytt

- Last ned frå detaljsida til ein film, ein episode eller ein serie – ikkje frå spelaren.
- Når du vel ein serie, vel du først den konkrete episoden. «Neste episode» kjem øvst når han
  finst; Spole lastar aldri ned ein heil sesong ved eit uhell.
- Film og episodar beheld valet ditt av lydspor, tekstspor og kjeldefil før den direkte-kompatible
  fila blir sett i kø.
- «Fortsett å sjå» bruker no serie-Thumb for episodar når tenaren leverer han, slik at rada ser
  samanhengande ut. Episodar i vanlege episodarader brukar framleis eige stillbilete.

## Avgrensingar

- Berre komplette filer som kan spelast direkte lokalt kan lastast ned. Livestreamar, DRM,
  plateavtrykk og media som treng omkoding blir forklarte og ikkje lagde i kø.
- Nedlasting finst berre for vaksne profilar på telefon og nettbrett. TV og barnemodus viser ikkje
  handlinga.
- Filer ligg privat i appen og er bundne til den serverkontoen og profilen som oppretta dei.
