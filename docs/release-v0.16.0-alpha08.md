# Spole 0.16.0-alpha08

Lokal signert testutgåve, bygg 51. Ikkje publisert på GitHub.

- Eiga personleg Seerr-historikk med eldre sider, oppdatering og feil/retry. Lesing opprettar ikkje varsel eller følgjar.
- Kvote og krav til godkjenning før sending. Filmkvote og sesongkvote blir vurderte kvar for seg, og stadfesta overskriding stoppar sending.
- Aktive følgjar og varsel blir bevarte når lista blir større enn 100 postar. Historikken blir tømd ved utlogging eller endra profil.
- Inkluderer alpha07-arbeidet: Jellyfin-bibliotek med mapper og bibliotekval som styrer innlasting, nye filmar/seriar og andre bibliotekrader; automatisk utviding av TV-sidemenyen og enklare aktivitetsikon.

Nye tekstar finst på nynorsk og engelsk. Dette fullfører ikkje heile 0.17, full engelsk omsetjing eller fysisk TV-støtte. Ekte førespurnad → nedlasting → import → varsel står att som eigargodkjend tenartest.
