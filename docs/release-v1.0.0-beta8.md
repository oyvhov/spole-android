# Spole 1.0.0-beta8

Ei roleg side for kvar smarte hylle, og hyller som kjem fram med ein gong.
Same pakkenamn og signatur som før; produksjonskode 145.

- **Sida for ei hylle** opnar på hylla sjølv: bakgrunnsbilete frå titlane, ei vifte av plakatar på
  breie skjermar, namnet og to knappar, «Overrask meg» og «Endre». Overrask meg opnar ein tilfeldig
  tittel du ikkje har sett. Tala står éin gong, på filteret for filmar og seriar.
- **Sortering og «Skjul sette»** på sida. Sorteringa blir lagra på hylla og gjeld òg rada på framsida.
  Titlar lagde til dei siste 14 dagane får eit «Ny»-merke.
- **Hyllene kjem fram med ein gong.** Det siste svaret frå tenaren blir hugsa, så flisa, rada på
  framsida og sida blir teikna straks, og det ferske svaret tek over etterpå.
- **Ei ny hylle står på framsida** med ein gong. Ei hylle frå ein mal startar på «Heile året»; vel du ein
  periode som ikkje har byrja, seier byggjaren når hylla kjem fram.
- **Fjernkontrollen held kolonna** ved raske trykk opp og ned i alle rutenett: bibliotek, hyller, søk,
  Oppdag, Aktivitet, førespurnader og barnemodus. Ned frå ein brytar i Tilpass-radene går til knappane
  i same rad.
- **Biblioteksfiltera påverkar ikkje lenger hyllene.**

Installer over førre versjon. Testutgåver må vere på i oppdateringsinnstillingane.
