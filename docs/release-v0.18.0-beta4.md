# Spole 0.18.0-beta4

- Legg til **Nedlastingar** for vaksne på mobil og nettbrett. Skjermen viser privat
  lagringsstatus, framdrift, pause/hald fram, prøv att, sletting og berre-Wi-Fi-val.
- Ferdige, direkte-kompatible Jellyfin- og Emby-filer spelar frå appen sin private cache utan å
  falle tilbake til nettverket.
- Kvar nedlasting er knytt til både den aktive profilen og den eksakte tenestekontoen. Titlar i
  det lokale biblioteket er krypterte; Media3-køen inneheld berre hasha identifikatorar.
- TV og barnemodus har framleis ikkje nedlasting eller offline-avspeling.

## Avgrensingar

- Berre komplette filer som tenaren uttrykkeleg kan levere direkte, kan lagrast. Live-TV, DRM,
  ISO/platemenyar og innhald som krev omkoding er ikkje nedlastbart.
- Chromecast er ikkje med i denne releasen.
