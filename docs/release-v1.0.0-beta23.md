Spole beta23 samlar to endringar:

- Stova kan opne Jellyfin- og Emby-titlar i Spole. Opninga fungerer når appen alt køyrer og etter kaldstart, og bruker den eksisterande kontoen i Spole.
- På TV kjem heile rada med medverkande fram under filmdetaljane. Korta får meir breidde når systemskrifta er stor.

Installer beta23 over ei tidlegare Spole-beta for å halde på innlogging og lokale val. Beta23 er ei førehandsutgåve.

Sjå `docs/LAUNCHER_LINK.md` for format og grenser for Stova-lenkjene, og `docs/VERIFICATION_v1.0.0-beta23.md` for bygg- og einingsresultat.
