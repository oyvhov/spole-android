# Spole 0.18.0-beta1

Ny beta-serie med ei meir gjennomtenkt bibliotekside for barn:

- Biblioteknamn ligg under bileta på mobil og nettbrett som standard, og innstillinga kan framleis endrast.
- Filmar og seriar er tekne bort som filter fordi biblioteka vanlegvis alt er delte slik på tenaren.
- Bibliotekssida kan sorterast etter lagt til, utgitt og vurdering.
- «Alle», «Ikkje sett» og «Favorittar» er dei relevante statusvala.
- Dato for når innhaldet vart lagt til blir henta frå Jellyfin/Emby og brukt i sorteringa.
