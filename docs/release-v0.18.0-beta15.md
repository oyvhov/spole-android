# Spole 0.18.0-beta15

- **Betre mobil-Hero:** Bakgrunnskunst frå filmen eller serien blir prioritert framfor miniatyrbilete med innebygd tekst. Logo og tittel blir viste separat.
- **Sveip med touch:** Heroen følgjer fingeren begge vegar, også mellom første og siste tittel. Toppmenyen står fast, og framsida kan framleis rullast nedover.
- **Enklare val:** Sideprikkane har større trykkflater. Sveiping startar ein ny pause før automatisk bytte; manuelle val fungerer også med reduserte rørsler.
- **Stor skrift:** Heroen kan vekse, og handlingsknappane kan bryte til neste rad.

Same pakkenamn og signatur som før. Oppdateringa bevarer kontoar, profilar og innstillingar.
