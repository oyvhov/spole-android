# Spole 1.0.0-beta37

Roleg Heim på TV, tydeleg fokus og sidebyte utan mørke. Produksjonskode 174.

- TV: Ned frå toppbiletet flyttar sida i éi rørsle, og kvar rad landar på same linje. Opp og Tilbake tek toppbiletet heilt tilbake, og Tilbake lukkar ikkje lenger Spole frå radene.
- Toppbiletet krysstonar ved byte og står i ro bak radene.
- «Løft» viser kortet med fokus tydeleg: større, med skugge og litt lys.
- Titlar, sidebyte og oppstart utan mørke mellomsider.
- Ingen avkappa kort eller faner, episodane innanfor tryggsona, og sidemenyen dempar sida bak.

Alt frå beta35 er med. Kjeldearkiva for FFmpeg og dei native undertekstbiblioteka ligg ved releasen.

Sjå [verifiseringa](https://github.com/oyvhov/spole-android/blob/main/docs/VERIFICATION_v1.0.0-beta37.md).
