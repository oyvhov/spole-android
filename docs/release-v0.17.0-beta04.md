# Spole 0.17.0-beta04

- Høgare og meir integrert TV-hero, med fullbreidde bakgrunnskunst og mjuk overgang til innhaldet.
- Filmatiske detaljsider med logo, omtale, episodar og medverkande.
- Kort episodeformat: S2 - E2. Clearlogo og episodelinje i TV-OSD har felles venstrekant.
- Emby bruker no den integrerte spelaren, sporval, neste episode, lokal framdrift og valfri Watch Next.
- Emby-bibliotek med filtrering, sidevis lasting og snarvegar. Ein liten meny erstattar dei store tenestefanene og hugsar sist valde tenar.
- Studio og produksjonsstatus er tekne ut av detaljfakta. Rotten Tomatoes blir vist når serveren leverer kritikarvurderinga.

Testutgåve. Formatstøtte avheng av Android-eininga og serveren; alle HDR-, surround- og undertekstvariantar er ikkje verifiserte. Live-TV, platemenyar og offline-nedlasting er ikkje del av denne integrasjonen.

Oppdater gjennom Spole med Testutgåver på. Kontoar og personlege val blir bevarte.
