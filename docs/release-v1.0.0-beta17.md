# Spole 1.0.0-beta17

Nytt «Neste episode», rolegare TV-sider og fokus som finn heim. Produksjonskode 154.

- Avspelaren: «Neste episode» er eit roleg hjørnekort utan bilete; nedteljinga fyller «Spel neste» sakte frå venstre.
- Heroen på Heim og i Bibliotek: biletet held fram under første rad og tonar ut i sida.
- Framsida viser ikkje Jellyfin-logo og namn ved radene, berre namnet der to tenarar har same rad.
- Bibliotek i menyen opnar biblioteksida, og Tilbake gir fokus til flisa eller «Bla i alt» du kom frå.
- Smarthylle-sida: utan «Overrask meg», «Endre» blant vala, bilete som byter seg.
- Oppdag: bakgrunnsbilete på «Dine førespurnader» og «Alle», namn på plakatar, og Tilbake til der du var.
- Søk på TV: pil ned når resultata, og fokus blir verande når lista rullar.
- Tilbake frå ein liknande tittel går til tittelen du kom frå; «ferdig» står berre på titlar som kan spelast.

Sjå [verifiseringa](https://github.com/oyvhov/spole-android/blob/main/docs/VERIFICATION_v1.0.0-beta17.md).
