# Spole 1.0.0-beta38

Tydeleg fokus utan glød, og rader som står stille. Produksjonskode 175.

- TV: Kortet med fokus veks, løftar seg og får ein skarp lys kant i staden for glød.
- TV: Ned går til rada under, også når kortet ved sida har to linjer tekst.
- TV: Bortover flyttar rada seg eitt kort per trykk, og fokus står i ro. Ei rad du kjem inn i ovanfrå eller nedanfrå, står stille.
- TV: Alle kort i ei rad er like høge, så sida under hoppar ikkje lenger.
- TV: Rullinga held farten mellom trykka, og kantane tonar ut utan å belaste grafikkbrikka.
- TV: Overskriftene på radene er mindre.

Alt frå beta37 er med. Kjeldearkiva for FFmpeg og dei native undertekstbiblioteka ligg ved releasen.

Sjå [verifiseringa](https://github.com/oyvhov/spole-android/blob/main/docs/VERIFICATION_v1.0.0-beta38.md).
