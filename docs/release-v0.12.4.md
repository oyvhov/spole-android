# Spole 0.12.4 – rolegare innloggingsvising

- Ei teneste som allereie er innlogga opnar no som ei kompakt stadfesting med grøn hake.
- Adresse, innloggingsmetode, kontofelt og utlogging er skjulte til brukaren vel å vise dei.
- Detaljane foldar seg mjukt inn og ut inne i den faste popupen, utan å flytte sjølve vindauget.
- Nye tenester går framleis rett gjennom den enkle adresse- og innloggingsflyten.
- Overskrifta seier no tenestenamnet når tenesta er innlogga, ikkje «Logg inn».
- Aktive Sonarr-nedlastingar toler no fleire episodar frå same sesongpakke utan at aktivitetslista krasjar.
- Køelement blir avdupliserte ved innlesing, med eit ekstra vern i sjølve lista mot identiske tredjeparts-ID-ar.

Oppdater over førre produksjonsversjon; ikkje avinstaller. Kontoar og lokale val blir bevarte.
GitHub-repoet er privat, så nedlasting krev innlogging med tilgang.
