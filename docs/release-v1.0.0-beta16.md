# Spole 1.0.0-beta16

Fokusringar som følgjer forma, og eit roleg Oppdag på TV. Produksjonskode 153.

- TV: fokusringen ligg på det du ser: rundt ansiktet på medverkande, rundt stillbiletet på episodar og på sjølve knappen, ikkje rundt den usynlege trykkflata.
- Lenker og faner som «Les meir» og «Alle 114» har luft rundt teksten; ringen skjer ikkje gjennom bokstavar.
- Heroknappane, «Trailer», «Følg i kalenderen», avspelaren og dialogane har synleg ring i knappens eiga form, og doble ringar er borte.
- Oppdag på TV: toppfeltet har fast høgd og to liner. Samandraget ligg på tittelsida.
- Tittelsida for titlar frå Seerr viser TMDB og Rotten Tomatoes, og medverkande er synlege utan å rulle.
- På TV-tittelsida når fjernkontrollen samandraget og kan opne heile teksten.

Sjå [verifiseringa](https://github.com/oyvhov/spole-android/blob/main/docs/VERIFICATION_v1.0.0-beta16.md).
