# Spole 1.0.0-beta1

- Spoleknappane held same plass når avspelinga buffer etter spoling.
- Mindre play-/pauseknapp med mørk bakgrunn og kvitt symbol.
- Enkle spolepiler utan teikna tal; kvart trykk spolar framleis 10 sekund.
- Nøytral tidslinje og rolegare tidsvising med jamne talbreidder.
- Samordna ikon, tekst og piler i innstillingsoversikta. Nedlastingar ligg under varsel.
- Ny versjonsnummerering: 1.0.0-beta1, beta2 og vidare, før stabil 1.0.0. Eksisterande installasjonar kan oppdatere som før.

Versjonskode 138. Oppdaterer eksisterande Spole med same signatur.

17 spelartestar med normal skrift og 6 med systemskrift 2.0 bestod før releasen. Ingen lint-feil. Testsuiten blir ikkje repetert etter versjonsauken i denne kjappe publiseringa.
