# Spole 0.14.1 · Finn noko nytt

Søk etter nye filmar og seriar er no ei tydeleg handling på framsida, rett under Spole og profilen.

- Ei diskret søkelinje integrert i toppen, utan eit stort kort eller ekstra knapp.
- Trykk på feltet: det glir over til søket i Oppdag, med tastaturet klart etter overgangen.
- Søketeksten blir bevart. Gamle type- og statusfilter blir nullstilte når du startar frå Heim.
- Vanlege besøk på Oppdag held fram der du var, utan automatisk tastatur.
- Feltet veks med tekststorleiken og følgjer Android si innstilling for animasjonar.

Innlogging, bibliotek og sending av førespurnader er uendra. Kan installerast over førre versjon
med den same signeringsnøkkelen.
