# Spole 0.16.0-beta04

Denne betaen er fokusert på oppstartsytelse og stabilare førsteoppleving frå kald start.

- Henta cached heimefeed tidleg i app-start, i staden for å vente på full live-refresh.
- Shorta `StartupReveal`-ventefaset til 280 ms, slik at skjermbiletet kjem fram raskare etter start.
- Holdt cache-synk på bakgrunn, så oppstarten blir lettare, men data er framleis ferske når tenesta er tilgjengeleg.
- Oppdatert dokumentasjon og verifiseringslogg for denne betaversjonen.

Dette er ein testutgåve.
