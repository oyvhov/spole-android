# Spole 0.17.0-beta01

Denne betaen samlar det nye biblioteket, meir oversiktlege innstillingar og ei betre avspelingsflyt på TV, nettbrett og telefon.

- **Ditt bibliotek:** vel Bibliotek som startside, bruk bibliotekbileta frå serveren, flytt eller skjul rader og tilpass kortformat og overskrift.
- **Ryddigare innstillingar:** mindre kontrollar, tydelege grupper, enklare menyredigering og namngjevne uttrykk du kan lagre. Innstillingssøk er fjerna.
- **Betre bilete:** stabil hero med bakgrunn frå filmen eller serien, riktige favorittomslag og betre handtering av mellomlagra kort.
- **Original oppstartslogo:** animasjonen får tid til å vise seg medan data og bilete lastar bak henne.
- **Episode og serie heng saman:** Gå til serien opnar same sesong; Tilbake fører deg til episoden igjen.
- **Kommande episodar:** tydeleg status og dato. Seerr kan supplere sesongar som finst i biblioteket; Sonarr er ikkje nødvendig.
- **Neste episode:** rett filkjelde blir brukt ved episodeskifte, også når episodane har ulike fil-ID-ar.
- **Undertekstar:** eitt sannsynleg tekstspor blir klargjort etter videostart, og tekstfiler blir gjenbrukte i minnet. Biletbasert tekst kan framleis krevje omkoding.
- **Hald fram med ein gong:** lokal framdrift legg det du nettopp såg øvst, utan å vente på serveroppdateringa.

Dette er ei testutgåve. Slå på **Testutgåver** under appoppdateringar for å finne henne frå ein stabil versjon. Kontoar og innstillingar blir bevarte ved oppdatering. Same Spole-logo og signeringsnøkkel er brukte.

Ei heilt ny sesong som medieserveren ikkje kjenner, og premieredata utan Seerr, er ikkje del av denne betaen.
