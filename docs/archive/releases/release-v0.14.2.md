# Spole 0.14.2 · Sesongar utan forvirring

- «Sjå sesongar» viser kva som finst, manglar eller er førespurt. Ingen sesongar er førehandsvalde.
- Delvis tilgjengelege og alt førespurde sesongar har ei eiga bjølle for varsel når Seerr melder sesongen tilgjengeleg. Dette sender ikkje ei ny førespurnad.
- Neste episode og premieredato blir viste når dei er kjende. Appen lovar ikkje automatisk nedlasting av framtidige episodar.
- Sesongflyten krev berre Seerr, ikkje direkte Sonarr-innlogging.
- Roligare popup med skeleton gjennom opninga, tydelegare status og støtte for stor tekst.

Kan installerast over førre versjon utan å logge inn på nytt. Same pakkenamn og signeringsnøkkel er bevarte.
