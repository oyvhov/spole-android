# Spole 0.16.0-beta03

Denne beta-utgåva er retta direkte mot opplevinga du meldte: kortare oppstart, ingen blanke sekund på Android 12+/TV og korrekt logo i launcher.

- Startdekk og oppstartsruten er stramma inn: kortare ventefase før heimraden kjem fram, og appen går raskare frå kald start.
- Android 12+ brukar no eit ekte Spole-wordmark i system-splasha, så det blir ikkje lenger ei tom bakgrunn med usynleg ikon.
- Launcher/TV-ikon er bygd med merke og ord, ikkje berre S-delen.
- Standardbildeføring er redusert for raskare første lasting utan å påverke detaljmodus.
- Versjonsnummer/byggnummer er oppdatert, og appen held fram med eksisterande signeringsnøkkel.

Dette er ein testutgåve.
