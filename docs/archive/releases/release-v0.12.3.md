# Spole 0.12.3 – strammare Oppdag og Aktivitet

- Fjerna den kunstige lufta mellom serienamn og episodetekst på korte titlar.
- Flytta den personlege Seerr-profilen til øvre høgre hjørne i Oppdag og Aktivitet, slik som på Heim.
- Samla vala i Oppdag på éi linje. Film/serie er direkte val, medan bibliotekstatus ligg i eitt ryddig menyval.
- Gjort Aktivitet rolegare: ferdige titlar er kompakte, og berre aktive førespurnader viser framdrift og varselval.
- Erstatta adminveggen av kjeldefilter med eitt oversiktsval, utan å endre kva administratoren kan sjå.
- Profilbilete blir halde i minnet ved rulling, så det ikkje blinkar bort når ei side blir bygd opp att.

Oppdater over førre produksjonsversjon; ikkje avinstaller. Kontoar og lokale val blir bevarte.
GitHub-repoet er privat, så nedlasting krev innlogging med tilgang.
