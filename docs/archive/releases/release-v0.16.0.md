# Spole 0.16.0

Jellyfin og Emby viser eige bibliotek sjølv om Seerr er nede. På mobil, nettbrett og TV kjem mediaradene fram så snart medietenaren har svart, utan å vente på Seerr, Radarr eller Sonarr. Når ei teneste blir fjerna, blir radene frå dei andre medietenestene ståande.

Heroen hentar større bilete med høgare kvalitet, og den gamle S-logoen er fjerna frå Android-oppstarten. Den originale Spole-logoen er bevart.

Utgåva inkluderer òg kompakt sesongvising på TV, episodar i nummerrekkjefølgje, valfri bakgrunnskunst på detaljsider, trykkbare medverkande og kopieringsknapp i felles Quick Connect-oppsett.

Oppdater over eksisterande Spole-installasjon. APK-en er signert med same nøkkel og bevarer kontoar og innstillingar. Dette er ei ordinær utgåve, ikkje beta.
