# Spole 0.17.0-beta21

- Fjerna overflødig «I biblioteket ditt» frå detaljvisinga i Jellyfin- og Emby-bibliotek.
- Numeriske aldersgrenser blir viste med eining, til dømes **15 år**.
- Bibliotekstatus i oppdagingsvisinga og klassifikasjonar som PG-13/TV-MA er bevarte.

**Ventetider og avspelingskode er uendra frå beta20.** Denne utgåva inneheld ikkje
ei retting for sovande mediediskar.

Universal-APK for telefon og TV, same pakkenamn/signatur, versjonskode **100**.
Oppdater med **Appoppdateringar → Sjekk no**, med testutgåver på.

FFmpeg-koden er uendra. Lisensane ligg i APK-en, og tilsvarande kjelde-/relenkingsarkiv
ligg ved releasen saman med R8-mapping, SHA256SUMS og kjeldecommit.
