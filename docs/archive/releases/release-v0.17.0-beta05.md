# Spole 0.17.0-beta05

- Automatisk refresh-rate switching når Android TV rapporterer ein trygg match for videoen.
- Nytt «Stats for Nerds»-panel i spelaren med codec, oppløysing, bitrate, HDR, frame rate,
  buffer og Direct Play/Transcode.
- Avspelingsfart utvida til 0.5x–2x.
- Emby playback-retry, Emby Connect-datalag, stabile lyd-/tekstspor og kjeldebevisste ratingfelt.

Testutgåve. Formatstøtte avheng av Android-eining, skjerm, lydutgang og medietenar.
Dolby Vision, lokal FFmpeg/MPV, Live TV og SyncPlay er ikkje del av denne utgåva.
