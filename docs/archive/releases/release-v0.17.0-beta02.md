# Spole 0.17.0-beta02

Lokal signert APK, versjonskode 81. Fyrste del av fase 4; sjå PHASE_4.md for attståande funksjonar.

- Episodesida prioriterer den aktuelle episoden og samandraget. «Serie» ligg ved favoritt. Sesongknappane viser berre namn.
- Mobilbiblioteket viser biblioteksnamn under bileta, med val for å skjule dei. Toppfiltera er fjerna på telefon.
- Innstillingskategoriar på mobil har ikon og tekst som kan brytast over fleire linjer.
- Fire undertekstuttrykk med førehandsvising og lagring. Tilgjengeleg i utsjånad og undertekstmenyen i spelaren.
- Undertekststorleiken følgjer videoflata på TV, nettbrett og mobil. Tekststilen kan endrast utan å starte videoen på nytt.

Gjeld den innebygde spelaren sine tekstbaserte undertekstar. Innebrend tekst og eksterne spelarar har eigen utsjånad.
