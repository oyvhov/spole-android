# Spole 0.16.0-beta02

Denne beta-utgåva tek med siste tv/UX-forbetringar, betre oppstart og betre lokaliserte tekstar.

- Oppstarten er raskare og meir responsiv på mobil og TV, med kortare, meir målretta innlastingsanimasjon.
- Biletlasting på TV er betre under aktiv scrolling via større minne-/diskcache og lågare kvalitetstap.
- Fellestenestekonfigurasjon (Jellyfin + Seerr) har betre påliteligheit og tydelegare feilmeldingar.
- Start/tekster i appen er flytta over til sentrale språkressursar for betre nynorsk språkstøtte.
- Frå starten blir katalogane synleggjorde frå eigne, lagra val, i staden for hardkoda filtrering av barnebibliotek.
- Oppstartsdekket held innhald ope kortare, men skjuler interaksjon framleis, noko som gir rolegare overgang på TV.
- Demo-opplegget er oppdatert med same datakvalitet som førre beta, med fokus på lågare UI-hopps i listene.

Dette er ein testutgåve. Oppgrader over tidlegare installasjon av Spole for å halde kontoar og innstillingar.
