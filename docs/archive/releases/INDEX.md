# Historiske release- og verifikasjonsnotat

Dette arkivet inneheld tidlegare release-notat og verifikasjonsrapportar. Filene er flytta hit for
å halde `docs/` retta mot gjeldande utvikling, drift og brukarrettleiing.

- Gjeldande release-notat ligg framleis i `docs/release-v<versjon>.md`.
- Gjeldande verifikasjon ligg framleis i `docs/VERIFICATION_v<versjon>.md`.
- Publiserte APK-ar, signerte kontrollsummar og mapping-filer ligg på
  [GitHub Releases](https://github.com/oyvhov/spole-android/releases).
- Filnamna i dette arkivet er medvite uendra, slik at ein kan slå opp ein bestemt versjon direkte.

Arkivet er historikk, ikkje ei skildring av dagens funksjonar eller teststatus. Bruk README, den
gjeldande release-verifikasjonen og `docs/RELEASE_WORKFLOW.md` for noverande status.
