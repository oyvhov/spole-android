# Spole 0.17.0-beta11

Dette er ei testutgåve med stabilitets- og brukaropplevingsarbeid frå milepålen Grunnfeste.

## Viktige endringar

- Hindrar usynlege popupark som fangar fokus etter avbrotne animasjonar eller raske Tilbake-trykk.
- Held alle kort i same rad på same kunstform, og fyller feil biletorientering med ei roleg bakgrunnskunst.
- Viser om avspelinga er direkte, direkte straum eller omkoda, og forklarer kvifor tenaren må omkode.
- Gir tidlegare melding ved buffering og prøver kompatibilitetsmodus før avspelinga har stått stille lenge.
- Gjer TV-fokus, spel av frå hero, namn på fokuserbare kontrollar og tryggsone tydelegare.
- Flyttar brukartekst frå kjeldekoden til ressursar for nynorsk, bokmål og engelsk.
- Forbetrar kalenderen, tidsformatet, medielinjene og visinga av Seerr-statusar ved språkbyte.

## Distribusjon

- Pakke: `app.reelstack`
- Testutgåve: `0.17.0-beta11`
- APK-en er signert med den eksisterande Spole-produksjonsnøkkelen.
- Releasen er ei prerelease og kan installerast over tidlegare Spole-betaer.

Sjå verifikasjonsrapporten for bygg, testar, signatur og SHA-256.
