# Spole 0.16.0-alpha24

Enklare innlogging for deg og dei du deler biblioteket med.

- Vel «Kom i gang» og logg inn med mobilgodkjenning eller Jellyfin-brukarnamn og passord.
- Opne den tilkopla Jellyfin-tenesta og vel «Del oppsett med ein brukar». Lenkja fyller inn adressene; kvar brukar loggar inn med sin eigen konto.
- Seerr er valfri. Når begge tenestene blir kopla til, stadfestar Spole at kontoane høyrer saman.
- På TV viser importert oppsett eit kort adressesamandrag og gir mobilgodkjenning fokus.
- Oppsettslenkjer byter aldri ut eksisterande kontoar. Innlogga brukarar får ikkje førstegongsoppsettet på nytt.

Quick Connect for begge tenestene krev Seerr med Quick Connect-støtte, kopla til same Jellyfin-tenar. Mobilgodkjenning krev at brukaren alt er innlogga i Jellyfin på ei anna eining. Nye brukarar kan velje brukarnamn og passord.

Oppsettslenkjer inneheld berre tenesteadresser. QR-paring og korte TV-oppsettkodar er ikkje med i denne utgåva.

Universal APK for Android 8 eller nyare, mobil og TV. Installer over eksisterande Spole for å behalde kontoar og innstillingar. Dette er ei testutgåve.
