# Spole 0.17.0-beta22

- Ved feil i direkte mediebehaldar prøver spelaren ompakking éin gong, med kopiering av støtta video og lyd. Posisjon og sporval blir bevarte.
- Betre fjernkontrollnavigering gjennom sesongar, også dei som alt ligg i biblioteket.
- Mindre kontotekst ved tittelen på TV gir meir plass til sesonglista.
- Kompakte bibliotekfilter med nedtrekksmenyar.
- Ryddigare endringslogg og fokusrammer som følgjer knappane.

Universal-APK for telefon og TV. Same signatur, versjonskode 101.
Oppdater via Appoppdateringar → Sjekk no, med testutgåver på.

Reserveavspeling er testa med syntetiske Emby-/Jellyfin-kjelder. Akkurat Kiki-fila og fysisk Pixel/Shield er ikkje verifiserte.
Kjend testavgrensing: automatisk retur frå minispelar til fullskjerm fekk tidsavbrot på emulatoren. Denne flyten er ikkje stadfesta i denne utgåva.
FFmpeg-koden er uendra; lisensar og tilsvarande kjelde-/relenkingsarkiv følgjer med.
