# Spole 0.16.0-alpha20

Denne utgåva gjer TV-framsida stødigare og innstillingane lettare å bruke.

- **TV:** rolegare rulling opp gjennom radene, jamnare kort og tydelegare knappar.
- **Neste episode:** få tilbodet før slutten, vel kor tid det skal visast og om neste episode skal starte automatisk. Automatisk overgang ventar til episoden er ferdig.
- **Lett TV-modus:** mindre animasjon og færre biletlagsbytte for tregare TV-ar. Fokusmarkeringa blir verande tydeleg.
- **Mobil:** sju oversiktlege innstillingskategoriar med gjennomgåande val, brytarar og knappar.
- **Jul og Halloween:** vel under Innstillingar → Utsjånad → Sesongtema. Jul gir logoen nisselue og legg til julelys, granbar, stjerner og snø. Halloween får spøkelse, edderkoppar og spindelvev. Du kan slå av pynten eller behalde henne utan rørsle i lettmodus.

Dette er ei testutgåve. Ha «Testutgåver» på, og vel **Sjekk no** under **Varsel og oppdatering → Appoppdateringar** for å hente henne på TV-en.

Pakke `app.reelstack`, versjonskode **63**, same signeringsnøkkel som tidlegare. Oppdateringa bevarer kontoar og innstillingar.

Verifisering og avgrensingar er dokumenterte i `docs/verification-v0.16.0-alpha20.md`. Yting på ein fysisk, svak TV er ikkje målt.
