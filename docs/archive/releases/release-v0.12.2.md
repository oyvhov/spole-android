# Spole 0.12.2 – roleg opning av popupar

- Fjerna det vesle etterhoppet ved opning: arket glir til sluttposisjonen utan fjør/sprett.
- Fast dialogramme blir målt frå vindauget sine faktiske rammer, ikkje ein storleik som blir oppdatert etter opning.
- Filmdetaljar får ein samla skeleton medan metadata blir henta. Ferdige detaljar tonar inn etter opningsrørsla, utan ny høgdeanimasjon.
- «Les heile omtalen» blir plassert i same layout som teksten, ikkje ei ramme seinare.
- Den faste X-knappen, rulling berre i innhaldet, kalender-retur og sperra lukking under sending er bevarte.

Oppdater over førre produksjonsversjon; ikkje avinstaller. Kontoar og lokale val blir bevarte.
GitHub-repoet er privat, så nedlasting krev innlogging med tilgang.
