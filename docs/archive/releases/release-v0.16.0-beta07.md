# Spole 0.16.0-beta07

Denne betaversjonen rettar appikonet for Android TV og legg tilbake originalt merkeikon (utan ordmerking) i launcher.

- `spole_launcher_foreground.xml` er sett tilbake til signatur-versjonen med berre merkeikonet.
- Søylerte oppstartsoppføringar knytt til ikonrepresentasjon på eldre TV-launcherar er testa i ny APK.
- Appen er elles berre justert med denne visuelle ikon-korrigeringa.

Dette er ein testutgåve.
