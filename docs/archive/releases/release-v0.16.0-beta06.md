# Spole 0.16.0-beta06

Denne betaversjonen er eit lite visuelt fix for at Android TV-launcher ikkje skal vise ein avgrensa S-variant av ikonet.

- Launcher-ikon går no via robust ikonressurs for å gje betre samsvar på TV.
- Legg til `android:roundIcon` med same ikonkjelde for meir stabil visning i ulike launcher-kontekstar.
- Versjonsnummer er oppdatert til ny beta.
- Hindrar mobil-lasta-oppe-spinner på øvste hjørne frå å stå permanent på oppstart:
  topprefresh på heimesida blir berre vist når brukaren sjølv trykker refresh.

Dette er ein testutgåve.
