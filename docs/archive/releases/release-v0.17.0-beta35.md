# Spole 0.17.0-beta35

Denne testutgåva rettar små og feilforma bilete på «Fortsett å sjå».

## Retta

- Resume-førespurnader til Jellyfin og Emby ber no om både `Primary` og `Thumb`.
- Breie 16:9-kort brukar Thumb/miniatyrbiletet når tenaren tilbyr det.
- Cache-versjonen er auka, slik at gamle poster-URL-ar ikkje blir viste ved oppstart etter oppdatering.

Oppdateringa bevarer innloggingar og brukarval. Ho er ei testutgåve; «Testutgåver» må vere på i
appoppdateringar for å finne henne.
