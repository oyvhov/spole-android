# Spole 0.16.0-alpha21

- Ny TV-spelar med ikon, tydeleg spolelinje og betre fjernkontrollnavigasjon. Pil venstre/høgre spol direkte når kontrollane er skjulte.
- Neste episode kjem som eit lite, dempa kort. Automatisk nedtelling startar før slutten, med tidspunktet du vel i innstillingane.
- Ryddigare filmdetaljar med mindre omslag. Titlar og status ligg inne i omslaga på Oppdag og Aktivitet.
- Meir jule- og Halloween-stemning i bakgrunnar og menyar.
- Fiksa favorittfilmar som ikkje opna, Bibliotek-knappen som hugsa feil mappe, og for store fokusrammer.
- TV-heroen er rydda, den samla rada heiter Sjå vidare, og eiga avspeling tek ikkje plass under Spelar no.
- Lesbar mobilmeny ved stor skrift.

Signert universal-APK for oppdatering av eksisterande Spole. Versjonskode 64.
Dette er ei testutgåve; ha Testutgåver på under Appoppdateringar.
