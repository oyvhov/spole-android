# Spole 0.18.0-beta13

- Mjukare overgang mellom Hero-bileta på TV. Neste bilete blir lasta på førehand og tonar inn over det førre.
- Bibliotekkort i barnemodus opnar biblioteket utan fast valramme og hake.
- «Byt profil» opnar raskare og med mindre rørsle på mobil og TV.
- «Legg til barneprofil» er fjerna frå profilpopupen. Du finn valet under «Tenestene dine».

Kontoar og lagra val blir bevarte. Dette er ei testutgåve; «Testutgåver» må vere på for å få henne gjennom appoppdateringar.

Testkontroll: 810 JVM-testar og 24 utvalde Android-testar på mobil og TV er stadfesta.
Éin TV-test bestod ved separat omkøyring etter at testskjermen forsvann i første køyring.
Ingen lint-feil. Barnemodus på mobil er dekt av Compose-testar, men ikkje manuelt kontrollert
med ein innlogga barneprofil.
