# Spole 1.0.0-beta19

Ingen flytande namn ved ikona på TV. Produksjonskode 156.

- Sidemenyen på TV viser ikkje lenger namnet på ikonet med fokus i ei boble over heroen.
- «Avspelingsval» i avspelaren og «Tilpass biblioteksida» i biblioteket viser heller ikkje namnet over biletet.
- Namna er framleis med for TalkBack.

Alt frå beta18 er med: den nye avspelaren med roleg OSD, eigne undertekstar og framdrift utan nett.
Kjeldearkiva for FFmpeg og dei native undertekstbiblioteka ligg ved releasen.

Sjå [verifiseringa](https://github.com/oyvhov/spole-android/blob/main/docs/VERIFICATION_v1.0.0-beta19.md).
