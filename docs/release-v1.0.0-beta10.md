# Spole 1.0.0-beta10

Smarte hyller med meir plakat og mindre tekst, på flisa, framsida, hyllesida og i byggjaren.
Same pakkenamn og signatur som før; produksjonskode 147.

- **Flisa i biblioteket er plakatane.** Tre plakatar frå hylla fyller flisa kant til kant, og namnet
  står på éi linje nedst med hylleikonet framfor. Undertittelen med regelen er borte; regelen finn du
  under «Endre».
- **Rada på framsida** har hylleikonet framfor tittelen, og det siste kortet i rada er «Sjå alle», som
  opnar heile hylla. Knappen under rada er borte.
- **Hyllesida på mobil:** filteret, sorteringa og «Skjul sette» står på éi rad som rullar sidelengs,
  så plakatane kjem høgare opp.
- **Byggjaren** har mindre tekst: forklaringane under Sjangrar, Stikkord og Når er borte. Periodane
  viser datoane sine i brikkene («Halloween · 20. okt.–1. nov.»), og lange sjangerlister faldar seg
  bak «Fleire sjangrar», med dei valde først.

Installer over førre versjon. Testutgåver må vere på i oppdateringsinnstillingane.
